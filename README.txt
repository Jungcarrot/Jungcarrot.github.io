해당 주소로 접속 시 웹사이트에 접속 가능하다.

계산기는 총 4가지이며, 회색 이름을 누르면 하위 빈 공간에 계산기가 등장하게 된다.
다른 페이지로 넘어갔다 돌아와도 빈칸에 입력해뒀던 내용은 localStorage에 저장된다.

"공격력 계산"
각 빈칸에 뜨는 값의 범위로 전체 입력 후 계산하기를 누르면 총 공격력이 출력된다. 모든 칸에 값을 입력해야한다.
오류확인 : 값이 입력되지 않거나 범위 밖의 값을 입력하게 되면 범위 내의 값을 입력하라는 경고창이 뜬다.

"농장 스킨 레벨 계산"
스킨 종류와 세부 스킨을 선택 후, 현재 스킨 레벨과 목표 스킨 레벨을 입력한다. 계산하기를 누르면 해당 레벨까지 필요한 고물 재료 수가 출력된다.
값이 입력되지 않거나 범위 밖의 값을 입력하게 되면 범위 내의 값을 입력하라는 경고창이 뜬다.
목표 레벨보다 현재 레벨이 높을 경우 목표 레벨이 현재 레벨보다 높아야한다는 경고창이 뜬다.

"신단 레벨 계산"
신단 종류를 선택 후 현재레벨과 목표레벨을 입력한다. 계산하기를 누르면 현재레벨부터 목표 레벨까지 필요한 호박석 수가 출력된다.
값이 입력되지 않거나 범위 밖의 값을 입력하게 되면 범위 내의 값을 입력하라는 경고창이 뜬다.
목표 레벨보다 현재 레벨이 높을 경우 목표 레벨이 현재 레벨보다 높아야한다는 경고창이 뜬다.

"특성 포인트 계산"
각 특성 별 현재 레벨을 입력한다. 계산하기를 누르면 최고레벨까지 필요한 포인트 수를 출력한다. 특성 별로 필요한 포인트 수를 나타내기도 하고, 총 포인트 수를 나타낼 수도 있다.
값이 입력되지 않거나 범위 밖의 값을 입력하게 되면 범위 내의 값을 입력하라는 경고창이 뜬다.
